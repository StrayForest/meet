# Product spec — Discovery, map and search — Architecture 1.3

User finds a credible **physical** activity for now/today/weekend quickly.

Eligible V1 supply: PUBLIC_VENUE, OUTDOOR, PRIVATE_HOME only. Online/hybrid is not a placeholder capability.

Home: city/area, search, quick time chips, Now/For You/Today/Weekend/Nearby. Event card represents concrete EventOccurrence while retaining Event identity.

Rank after eligibility by time, distance, interests, language, social availability, quality/trust, social signal, freshness/diversity. Optimize toward successful attendance.

Admission/ticket and Meet social participation are separate display/rank signals.

Low-density: expand radius/date, include licensed imported physical supply, explain widened area, offer create-event. Never fabricate/hide distance.

Map: bounded viewport clusters; private-home public coarse point only. Search: FTS/trigram/structured filters. High-impact actions revalidate current occurrence truth.
