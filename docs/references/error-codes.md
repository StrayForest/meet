# Stable API error-code baseline

Use Problem Details plus stable `code`. Additive codes are allowed; supported clients handle unknown codes generically/safely.

## Auth/account
AUTH_REQUIRED, AUTH_INVALID, ACCOUNT_RESTRICTED, ACCOUNT_SUSPENDED, AGE_NOT_ELIGIBLE, STAFF_AUTH_REQUIRED, STAFF_SCOPE_FORBIDDEN.

## Client compatibility
CLIENT_VERSION_UNSUPPORTED, CLIENT_CAPABILITY_REQUIRED, CLIENT_RUNTIME_UNSUPPORTED, SERVICE_MAINTENANCE.

`CLIENT_VERSION_UNSUPPORTED` is used only after deliberate minimum-supported-version policy, not as convenience for ordinary API changes.

## Event/occurrence
EVENT_NOT_FOUND, EVENT_ALIAS_RESOLVED, EVENT_NOT_PUBLISHED, EVENT_CANCELLED, OCCURRENCE_NOT_FOUND, OCCURRENCE_CANCELLED, OCCURRENCE_JOIN_CLOSED, OCCURRENCE_CAPACITY_FULL, EVENT_NOT_ELIGIBLE, EVENT_VERIFICATION_REQUIRED, EVENT_EDIT_CONFLICT, OCCURRENCE_VERSION_CONFLICT, RECURRENCE_RULE_UNSUPPORTED, ONLINE_ONLY_EVENT_UNSUPPORTED.

Alias resolution normally redirects/returns canonical resource rather than surfacing an error; `EVENT_ALIAS_RESOLVED` is internal/debug/optional response metadata, not a user-facing failure.

## Admission
EXTERNAL_TICKET_URL_UNAVAILABLE, ADMISSION_MODE_UNSUPPORTED, INTERNAL_TICKETING_DISABLED.

Admission errors must not be reused as social participation errors.

## Participation
PARTICIPATION_DISABLED, ALREADY_JOINED, JOIN_REQUEST_PENDING, WAITLIST_DISABLED, WAITLIST_ALREADY_JOINED, WAITLIST_OFFER_EXPIRED, PARTICIPATION_NOT_FOUND, PARTICIPATION_STATE_CONFLICT.

## Pod/chat/realtime
POD_FULL, POD_NOT_ELIGIBLE, CONVERSATION_FORBIDDEN, MESSAGE_RATE_LIMITED, USER_BLOCKED, REALTIME_SUBSCRIPTION_FORBIDDEN, REALTIME_CURSOR_EXPIRED.

## Organization
ORG_NOT_FOUND, ORG_PERMISSION_DENIED, ORG_CLAIM_PENDING, ORG_NOT_VERIFIED.

## Safety/private location
REPORT_INVALID_TARGET, CONTENT_POLICY_BLOCKED, PRIVATE_LOCATION_FORBIDDEN, PRIVATE_LOCATION_NOT_YET_DISCLOSED, STRONG_VERIFICATION_REQUIRED.

## Media
MEDIA_NOT_READY, MEDIA_REJECTED, MEDIA_UPLOAD_INVALID.

## Generic
VALIDATION_FAILED, IDEMPOTENCY_CONFLICT, RATE_LIMITED, CONFLICT, EXTERNAL_PROVIDER_UNAVAILABLE, STALE_RESOURCE, INTERNAL_ERROR.

Do not expose sensitive moderation/risk internals, provider raw errors, SQL strings or precise private-location details through Problem Details.
