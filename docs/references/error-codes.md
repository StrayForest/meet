# Stable API error-code baseline

Use RFC Problem Details plus stable `code`. Additive codes are allowed; clients must handle unknown codes generically.

## Auth/account
AUTH_REQUIRED, AUTH_INVALID, ACCOUNT_RESTRICTED, ACCOUNT_SUSPENDED, AGE_NOT_ELIGIBLE.

## Event
EVENT_NOT_FOUND, EVENT_NOT_PUBLISHED, EVENT_CANCELLED, EVENT_JOIN_CLOSED, EVENT_CAPACITY_FULL, EVENT_NOT_ELIGIBLE, EVENT_VERIFICATION_REQUIRED, EVENT_EDIT_CONFLICT.

## Participation
ALREADY_JOINED, JOIN_REQUEST_PENDING, WAITLIST_ALREADY_JOINED, WAITLIST_OFFER_EXPIRED, PARTICIPATION_NOT_FOUND, PARTICIPATION_STATE_CONFLICT.

## Pod/chat
POD_FULL, POD_NOT_ELIGIBLE, CONVERSATION_FORBIDDEN, MESSAGE_RATE_LIMITED, USER_BLOCKED.

## Organization
ORG_NOT_FOUND, ORG_PERMISSION_DENIED, ORG_CLAIM_PENDING, ORG_NOT_VERIFIED.

## Safety
REPORT_INVALID_TARGET, CONTENT_POLICY_BLOCKED, PRIVATE_LOCATION_FORBIDDEN.

## Generic
VALIDATION_FAILED, IDEMPOTENCY_CONFLICT, RATE_LIMITED, CONFLICT, EXTERNAL_PROVIDER_UNAVAILABLE, INTERNAL_ERROR.

Do not expose sensitive moderation/risk internals through error details.
