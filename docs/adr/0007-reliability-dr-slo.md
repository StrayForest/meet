# ADR-0007 — Reliability, error budgets and DR are business-impact driven
Status: ACCEPTED

Use user-journey SLIs/error budgets, not uptime alone. Primary Finland, recovery Stockholm. Start with tested restore/recreation; add continuously replicated/warm recovery before business/safety impact demands mature RPO≤5m/RTO≤60m. No active-active merely for valuation. Capacity/service extraction follows workload evidence, not MAU.
