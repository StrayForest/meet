# Architecture Decision Records

`09_FIXED_ARCHITECTURE_DECISIONS.md` lists already accepted baseline decisions. New architecture changes receive a numbered ADR here before implementation.

Naming: `ADR-031-short-title.md`, incrementing from existing baseline IDs.

Status: PROPOSED → ACCEPTED / REJECTED / SUPERSEDED.

Use `TEMPLATE.md`. An ADR changes architecture only after explicit approval; creating a proposal is not approval.
