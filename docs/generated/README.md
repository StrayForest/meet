# Generated documentation

This directory is for machine-generated, repository-readable truth once code exists, e.g.:
- DB schema summary from Drizzle migrations;
- OpenAPI snapshots/client matrix;
- event/domain message catalog;
- architecture dependency graph;
- design-token generated reference;
- analytics event catalog.

Generated files include a header with generator command/source. CI fails when generated truth is stale. Do not hand-edit generated output.
