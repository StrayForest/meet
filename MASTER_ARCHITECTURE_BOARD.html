7. Non-negotiable implementation rules

  1. Event is the core product entity.
  2. Backend starts as modular monolith, not microservices.
  3. PostgreSQL is authoritative; Valkey is ephemeral.
  4. REST + OpenAPI are the primary contracts.
  5. Retry-prone writes are idempotent.
  6. Domain side effects use transactional outbox.
  7. First-party IDs use UUIDv7.
  8. Time is UTC plus IANA timezone where local semantics matter.
  9. Imported events preserve provenance and rights metadata.
  10. Country differences live in country configuration.
  11. Initial public network is 18+.
  12. Private-home host requires strong identity verification.
  13. Exact home address is never in generic public DTOs.
  14. No passport scans/numbers stored by Meet.
  15. No random DMs.
  16. No public star rating for people.
  17. AI moderation is triage/pre-screening, not sole irreversible authority.
  18. Recommendation objective is successful offline attendance.
  19. Admin is isolated, MFA protected and audited.
  20. Architecture changes require ADR, migration and rollback.
